🚀 CÁC BƯỚC TRIỂN KHAI (THEO THỨ TỰ)
Bước 1: Backup trang chủ hiện tại
Trước khi đụng gì cũng cứ copy nguyên shortcode trang chủ cũ vào 1 file .txt lưu lại. Lỡ có gì còn rollback được.
Bước 2: Tạo Contact Form 7
Vào Liên hệ > Thêm mới trong WordPress, tạo form với các field:
<label>Họ và tên (bắt buộc)
    [text* your-name placeholder "Nhập họ tên của bạn"]</label>

<label>Số điện thoại (bắt buộc)
    [tel* your-phone placeholder "0xxx xxx xxx"]</label>

<label>Bạn quan tâm khóa nào?
    [select your-course "Tư vấn cho tôi" "Khóa Makeup Cá Nhân" "Khóa Makeup Chuyên Nghiệp"]</label>

<label>Lời nhắn (không bắt buộc)
    [textarea your-message x4 placeholder "Bạn có câu hỏi gì cho Lily Chen?"]</label>

[submit "🎁 Nhận tư vấn miễn phí"]
Sau khi save, CF7 sẽ cho bạn 1 shortcode dạng [contact-form-7 id="123" title="..."] — copy số ID đó.
Bước 3: Thay ID form vào shortcode trang chủ
Trong file lilychen-homepage.txt, có 2 chỗ ghi id="REPLACE_ID" — thay bằng ID thật của form vừa tạo. Nếu muốn track riêng conversion từ Hero vs Final CTA, tạo 2 form khác nhau với tên khác nhau.
Bước 4: Thay ID hình ảnh
Trong code có các ID hình ảnh placeholder:

bg="276" → background hero section
bg="376" → background final CTA
img="285", img="288", img="289" → icon trong 3 lý do
bg="284", bg="283" → 2 khóa học
ids="341,342,343,344" → gallery Before/After

Cách lấy ID hình: Vào WordPress > Media Library > click vào hình > nhìn URL có ?attachment_id=XXX hoặc xem ô "Attachment ID" bên phải. Thay các số đó vào code.
Bước 5: Paste code shortcode

Vào Trang > Tất cả trang > Trang chủ > Chỉnh sửa
Chuyển sang chế độ Text/Code (không phải Visual)
Xóa toàn bộ nội dung cũ
Paste nội dung từ lilychen-homepage.txt
Bấm Cập nhật

Bước 6: Paste CSS

Vào Flatsome > Advanced > Global Custom CSS
Paste toàn bộ nội dung lilychen-custom.css vào ô bên dưới (nếu có CSS cũ, để xuống dưới)
Bấm Save Changes

Bước 7: Test

Mở trang chủ ở chế độ ẩn danh (incognito) → đảm bảo không bị cache
Test trên cả desktop + mobile
Click vào nút "Nhận tư vấn lộ trình" → phải scroll xuống form
Submit form thử → check email có nhận được không
